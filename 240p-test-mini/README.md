# 240p Test Suite (NES)

`240pee.nes`: Damian Yerrick's NES port of Artemio Urbina's 240p Test Suite,
release v0.23, from https://github.com/pinobatch/240p-test-mini (GPL-2.0 or
later, see `LICENSE`; the source is in that repository). UxROM (mapper 2),
64 KB PRG ROM, 8 KB CHR RAM, vertical mirroring.

`tests/test_mappers.cpp` runs it past the credits into the PLUGE test.
