# F-FF

`f-ff_v1.nes`: a racing game by Pubby (2018, MIT license, see `LICENSE`),
from the retrobrews collection (https://github.com/retrobrews/nes-games,
`fff.nes`), released at https://forums.nesdev.com/viewtopic.php?f=33&t=16993.
UxROM (mapper 2), 64 KB PRG ROM, 8 KB CHR RAM, horizontal mirroring.

`tests/test_mappers.cpp` runs it past the title and difficulty screens into a race.
