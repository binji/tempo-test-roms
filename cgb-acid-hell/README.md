# cgb-acid-hell

Matt Currie's cgb-acid-hell (MIT, see `LICENSE`, from https://github.com/mattcurrie/cgb-acid-hell),
prebuilt as in the game-boy-test-roms v7.0 release (https://github.com/c-sp/game-boy-test-roms):
`cgb-acid-hell.gbc` and its expected picture `reference.png`, and `reference.txt`, the same in
RGB555 colors (`tools/png_rgb555.py`). test_gbc runs it until it executes `LD B,B` and compares.
