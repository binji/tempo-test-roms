# mGBA test suite

Jeffrey Pfau's GBA test suite, the build mGBA publishes
(https://s3.amazonaws.com/mgba/suite-latest.zip, built 2026-07-08 from
https://github.com/mgba-emu/suite e6942030; MIT, see `LICENSE`). A menu of suites (memory,
I/O reads, timing, timers, DMA, SIO, BIOS math, ...), each counting its subtests passed.
